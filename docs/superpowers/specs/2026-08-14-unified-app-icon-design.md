# 统一应用图标设计

## 目标

使用用户提供的蓝绿色日历勾选图，统一替换 samuel 的工作台在 Windows 桌面快捷方式、浏览器页签、主屏幕图标和应用品牌区域中的图标，同时保留各业务模块原有的独立图标。

## 图标来源

- 源文件：`codex-clipboard-9670485c-4250-4efd-ae42-17d39866eb1f.png`
- 源尺寸：1254 × 1254 像素
- 源格式：PNG，24 位 RGB，无透明通道
- 使用原则：保留原始构图、色彩和黑色外缘，不重新生成或重绘图案。

源文件位于系统临时目录，因此实施时必须将规范化后的正式资源保存进项目，桌面快捷方式不得继续引用临时路径。

## 资源输出

项目内新增一组由同一源图生成的正式资源：

- 1024 × 1024 PNG：应用和高分辨率品牌展示。
- 512 × 512 PNG：应用左上角品牌区域。
- 180 × 180 PNG：Apple Touch Icon。
- 64 × 64 PNG：浏览器页签图标。
- 多尺寸 ICO：包含 16、24、32、48、64、128 和 256 像素，用于 Windows 快捷方式。

缩放必须保持 1:1 比例，并使用高质量重采样，不裁切主体，不增加文字、水印或额外背景。

## 应用替换范围

- `index.html` 的浏览器 favicon 指向新 64 × 64 图标。
- `index.html` 的 Apple Touch Icon 指向新 180 × 180 图标。
- 普通外观侧栏左上角品牌标志改为新 512 × 512 PNG。
- Neo 外观侧栏左上角品牌标志使用同一新 PNG，不再使用旧 Neo 品牌图标。
- 浏览器页面标题、应用名称和各模块图标保持不变。
- 首页、今日计划、自媒体、开发、咨询、健身、饮食、娱乐、读书、思考和设置的模块图标不替换。

## Windows 桌面快捷方式

- 保留现有桌面快捷方式名称 `samuel的工作台.lnk`。
- 快捷方式继续启动项目根目录中的 `启动木子工作台.bat`。
- 工作目录保持项目根目录。
- 图标位置改为项目内持久保存的多尺寸 ICO 文件。
- 不修改其他桌面快捷方式，也不删除原 `.bat` 启动文件。

## 缓存与更新行为

- 新资源使用带版本号的文件名，避免浏览器继续显示旧 favicon。
- 构建后由现有桌面启动流程检测新版资源并安全重启旧服务。
- Windows 若暂时缓存旧快捷方式图标，重新读取快捷方式或刷新桌面后应显示新图标；快捷方式本身的图标路径必须已更新。

## 验收标准

- 浏览器页签显示用户提供的新图标。
- 普通外观和 Neo 外观的应用左上角显示同一个新品牌图标。
- 桌面 `samuel的工作台.lnk` 使用新图标，双击后仍能启动正式应用。
- 所有图标文件位于项目目录，不依赖系统临时文件。
- 各模块专属图标保持不变。
- 构建、组件测试、产物测试和桌面启动检查通过。

## 不在本次范围

- 不重新设计或修复源图。
- 不替换业务模块图标。
- 不制作原生 Windows 安装包或 `.exe`。
- 不改变正式应用功能、数据结构或界面布局。
