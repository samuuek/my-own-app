# iOS 系统原生配色 Demo 设计

## 目标

在不改变现有进度与倒计时 Demo 的信息架构、文案和交互逻辑的前提下，将当前偏青绿色、彩色渐变较明显的视觉调整为更接近 iPhone 系统应用的克制配色。

## 视觉方向

采用 iOS 浅色模式常见的中性灰背景、白色内容表面和系统蓝交互色。整体参考 iPhone 的“设置”“提醒事项”和“健康”应用气质，但不逐像素复制任何单一应用。

核心色彩：

- 页面背景：`#F2F2F7`
- 一级卡片：`rgba(255, 255, 255, 0.82)`
- 主文字：`#1C1C1E`
- 次级文字：`#8E8E93`
- 分割线：`#D1D1D6`
- 系统蓝：`#007AFF`
- 成功绿：`#34C759`
- 提醒橙：`#FF9500`
- 危险红：`#FF3B30`

## 组件调整

- 页面背景去除大面积青色与暖色光斑，改为低对比度的系统灰和非常轻微的冷白渐变。
- 侧栏、顶部栏和卡片使用白色半透明表面，降低玻璃材质的染色与阴影强度。
- 主按钮、选中导航、进度环和主要进度条统一使用系统蓝。
- 长期目标进度使用成功绿；日期倒计时使用提醒橙；计时停止或危险反馈保留系统红。
- 输入框、弹窗、抽屉和设置项统一使用白色表面、浅灰描边和 14—22px 圆角。
- 保留现有布局、响应式规则、按钮行为、倒计时逻辑、引导流程和示例数据。

## 可读性与状态

- 正文和主标题对比度以主文字色为基准，不使用浅灰承载关键内容。
- 次级信息使用 `#8E8E93`，但按钮文字和小字号说明保持足够清晰。
- 不只依赖颜色区分状态，现有文字标签、数字和按钮文案继续保留。
- 悬停、按下和选中状态通过背景深浅、轻微位移和描边共同表达。

## 验收标准

- 打开页面后整体观感明显接近 iPhone 浅色系统界面，而不是青绿色网页仪表盘。
- 页面背景、卡片、导航、按钮、进度、弹窗和抽屉使用同一套色彩规则。
- 桌面和窄屏布局均无溢出，所有现有交互仍可使用。
- 页面无脚本错误，Demo 文件仍保持独立运行且不连接正式数据。

## 不在本次范围

- 不增加深色模式。
- 不改变布局、信息层级、示例数据或功能。
- 不修改正式 React 应用的主题系统。
- 不引入第三方 UI 或图标依赖。
