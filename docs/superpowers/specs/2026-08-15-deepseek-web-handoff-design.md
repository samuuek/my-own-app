# 思屿 DeepSeek 免费网页版往返设计

## 目标

让用户无需配置 API Key，使用自己的 DeepSeek 网页账号获得对话反馈，并将回答带回思屿继续沉淀。思屿负责整理问题、复制内容、打开官网和导入回答，但不读取或保存用户的 DeepSeek 登录凭据。

## 范围

- 新增“DeepSeek 免费网页版”对话服务。
- 提供“复制问题并打开 DeepSeek”与“粘贴 DeepSeek 回答”的完整往返流程。
- 保留现有 API 模型能力，并将其收纳为默认折叠的高级配置。
- 对剪贴板权限失败提供手动粘贴降级方案。
- 不自动抓取 DeepSeek 页面内容，不检测登录状态，不保存账号、密码、Cookie 或网页会话。

## 用户流程

1. 用户在思考空间选择“DeepSeek 免费网页版”。
2. 用户输入问题并点击“打开并提问”。
3. 思屿将必要的议题上下文、最近对话和本次问题整理为一段可直接发送的提示词，写入剪贴板。
4. 思屿在新标签页打开 `https://chat.deepseek.com/`，当前页面进入“等待带回答回来”状态。
5. 用户在 DeepSeek 登录自己的账号，粘贴问题并完成对话。
6. 用户复制 DeepSeek 回答，返回思屿并点击“粘贴 DeepSeek 回答”。
7. 思屿读取剪贴板并展示可编辑预览；用户确认后，回答以 AI 消息保存到当前议题。
8. 如果浏览器拒绝读取剪贴板，思屿直接展示手动粘贴输入框，后续确认流程不变。

用户取消导入或返回后未粘贴回答时，原有对话和草稿保持不变。

## 界面设计

### 对话服务抽屉

- 将标题“模型与 API”改为“对话服务”。
- 顶部主服务为“DeepSeek 免费网页版”，说明文案为“登录自己的账号即可免费使用”。
- 主服务不显示“已连接”，而显示不依赖登录检测的“网页版可用”。
- 提供简短隐私说明：思屿不会获取 DeepSeek 账号、密码或登录状态。
- 现有豆包、千问、DeepSeek API 和自定义 API 放入“API 高级配置”折叠区域，保留现有可用状态与本地密钥说明。

### 对话区域

- 选择免费网页版时，发送按钮的含义改为“打开并提问”。
- 打开官网后，在对话区域显示非阻塞状态条：“问题已复制。获得回答后，回到这里继续。”
- 状态条提供主操作“粘贴 DeepSeek 回答”和次操作“再次复制问题”。
- 导入时使用轻量预览对话框，允许编辑、确认保存或取消。
- API 模型继续使用现有的站内直接发送流程。

视觉上沿用现有低饱和蓝绿色、开放面板和细边框体系，不引入新的页面结构或装饰风格。

## 组件与职责

### Web 对话服务描述

在前端模型类型中加入服务种类，区分：

- `demo`：现有本地演示回复。
- `api`：通过本地服务调用的 API 模型。
- `web-handoff`：通过外部网页往返的服务。

DeepSeek 免费网页版是静态可用的 `web-handoff` 服务，不由 `/api/models` 的密钥状态控制。

### 提示词整理器

独立的纯函数负责生成带往返说明的文本，输入包括议题标题、最近对话和当前问题。为避免复制过长内容，只携带当前议题标题和最近 10 条非空消息；本次问题只出现一次。输出不包含私人旁注、资料、纪要或导图内容，除非用户已经主动将这些内容写入对话。

### 网页往返控制器

负责：

- 写入剪贴板。
- 在新标签页打开 DeepSeek 官网。
- 保存当前议题的临时“等待回答”界面状态。
- 在浏览器拒绝弹窗或剪贴板权限时返回明确错误。

等待状态只保存在当前浏览器会话中，不写入永久数据；刷新后不恢复提示条，但已经保存的消息不受影响。

### 回答导入器

负责从剪贴板取得文本、展示预览并提交。确认后复用现有消息保存接口，以 `assistant` 角色写入当前议题，并记录模型 ID 为 DeepSeek 免费网页版服务 ID。空文本、超长文本和读取权限失败均在预览前处理。

## 数据流

```text
当前议题 + 最近消息 + 新问题
            ↓
       提示词整理器
            ↓
       浏览器剪贴板 ──→ DeepSeek 网页
                              ↓
思屿导入预览 ←── 浏览器剪贴板 ←── 用户复制回答
      ↓
现有本地消息保存接口
```

外部网页与思屿之间没有直接网络通信。DeepSeek 登录信息始终留在 DeepSeek 页面及浏览器管理的会话中。

## 错误与降级处理

- 写入剪贴板失败：保留整理后的问题，显示可手动复制的文本框，并仍允许用户打开官网。
- 新标签页被拦截：提示用户允许弹窗，并提供普通链接按钮；已经复制的问题不会丢失。
- 读取剪贴板失败：立即打开手动粘贴预览框。
- 剪贴板为空：提示“还没有检测到回答”，不创建消息。
- 回答超过后端单条消息上限：在本地预览时阻止提交，并提示用户缩短内容。
- 保存失败：保留预览内容与等待状态，允许重试。

## 安全与隐私

- 不请求 DeepSeek 密码、Cookie、Token 或网页存储权限。
- 不注入脚本、不抓取 DeepSeek 页面，也不尝试绕过跨域限制。
- 仅在用户明确点击时读写剪贴板。
- 导入前必须展示内容并由用户确认。
- 不将 DeepSeek 回答发送到现有 API 模型；确认后只写入思屿本地数据。

## 测试与验收

### 单元与组件测试

- 免费网页版服务始终可选择，且不显示虚假的登录或连接状态。
- 提示词包含议题标题、最近 10 条消息和本次问题，且不重复本次问题。
- 点击“打开并提问”会写入剪贴板并打开正确的 HTTPS 地址。
- 打开后显示等待状态和两个后续操作。
- 剪贴板回答进入可编辑预览，确认后保存为 AI 消息。
- 剪贴板读取失败时出现手动粘贴输入框。
- 空回答和超长回答不会保存。
- API 模型的原有站内发送流程保持不变。

### 浏览器验收

- 在桌面尺寸完成一次复制、打开官网、返回、导入和保存流程。
- 模拟弹窗拦截及剪贴板权限拒绝，确认降级操作可完成。
- 在移动尺寸确认抽屉、状态条和预览对话框不溢出。
- 确认页面文案没有声称能够读取登录状态或自动获取网页回答。

## 非目标

- 不提供 DeepSeek 官方 API 的免费额度。
- 不自动填写或提交 DeepSeek 网页输入框。
- 不自动同步、抓取或监控 DeepSeek 网页回答。
- 不开发浏览器扩展或桌面级浏览器自动化。
- 不移除现有 API Key 模型能力。
