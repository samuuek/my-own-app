# 简洁进度与倒计时体验设计

## 目标

优化 samuel 的工作台，使用户无需复杂设置，就能在首页一眼看到今天完成了多少、长期目标推进到哪里、重要日期还有多久，并能为今日任务快速启动倒计时。

本次采用渐进式优化：保留现有模块和操作习惯，重新组织首页信息层级，并新增轻量的目标、重要日期和任务计时能力。不会引入复杂的目标树、强制里程碑或自动规划。

## 体验原则

1. 首页先回答“今天完成得怎么样”，再展示“接下来有什么重要日期”和“长期目标进展如何”。
2. 已经存在于工作台的数据尽量自动汇总，避免重复填写。
3. 新功能均可直接跳过，不阻塞原有使用流程。
4. 常用设置直接显示，高级设置默认折叠。
5. 倒计时只作为提醒，不制造娱乐、阅读和生活事项的逾期压力。

## 首页结构：A 分层总览

首页按以下顺序展示：

### 第一层：今日总进度

顶部使用一个总进度环和五项状态摘要：

- 今日任务：已完成数 / 总数。
- 阅读：今日阅读页数；没有记录时显示“未记录”。
- 健身：今日训练完成、进行中或未安排。
- 饮食：今日已记录餐次数 / 计划餐次数；没有计划时只显示已记录数。
- 思考：今日主复盘是否已保存，以及完成度。

总进度只统计当天有实际目标或记录的项目，避免空模块拉低进度。今日任务占 50%，阅读、健身、饮食和复盘共同占 50%；没有目标的生活模块不进入分母。

### 第二层：重要日期倒计时

首页展示最近三个重要日期，每项显示名称、目标日期和“还有 X 天 / 今天 / 已过 X 天”。

倒计时来源包括：

- 自动提取：开发里程碑、咨询交付物和自媒体计划发布日期。
- 手动补充：生日、考试、旅行、纪念日和其他重要日期。

自动来源保留跳转链接，点击返回原模块。手动日期支持新增、编辑、隐藏和软删除。默认不展示已经过去的日期；用户可在历史列表查看。

### 第三层：长期目标

首页展示最多四个进行中的长期目标。每个目标包含名称、目标日期、当前进度和关联来源。

目标支持：

- 自动关联书籍：按当前页 / 总页数计算。
- 自动关联开发项目：按已完成工作项 / 全部工作项计算。
- 自动关联健身：按用户填写的目标次数与实际完成次数计算。
- 手动目标：直接填写 0—100% 进度。
- 自动目标允许手动修正显示进度；清除修正后恢复自动计算。

长期目标的创建表单只要求名称和类型。目标日期、关联记录和手动进度按所选类型逐步出现。

### 第四层：今日任务与计时器

今日时间线和待安排事项保留。每条未完成任务增加一个计时按钮：

- 点击后选择 25、45、60 分钟或自定义分钟数。
- 启动后显示剩余时间，并提供暂停、继续和结束。
- 同一时间只允许一个计时器运行；启动新计时器前询问是否结束当前计时。
- 计时结束后在页面顶部显示提醒，并播放一次轻提示音。
- 提示音可在设置中关闭。
- 刷新页面或重新打开工作台后，根据保存的结束时间恢复正确剩余时间。
- 计时结束不会自动将任务标记为完成，由用户决定是否完成。

## 简洁设置与首次引导

首次进入新版工作台时显示三步引导：

1. 选择常用模块，默认全选，决定首页今日状态显示哪些模块。
2. 选择三种现有外观之一及浅色 / 深色主题。
3. 选择每周从星期一或星期日开始，并确认是否开启计时提示音。

用户可以跳过引导，所有选项都有安全默认值。完成或跳过后不再自动出现，可从设置页重新打开。

设置页重组为：

- 常用设置：常用模块、外观、主题、每周起始日、计时提示音。
- 数据安全：保存、备份、恢复、导出和回收站，保持现有能力。
- 高级设置：日期格式、首页摘要细节和其他低频选项，默认折叠。

## 数据设计

新增数据库迁移，包含：

- `important_dates`：名称、目标日期、类别、来源模块、来源类型、来源 ID、是否首页显示、创建更新时间和软删除时间。手动日期作为正式记录保存；自动日期由现有模块实时派生，不复制到该表。
- `long_term_goals`：名称、类型、目标日期、来源模块、来源类型、来源 ID、目标值、手动进度、进度修正、状态、创建更新时间和软删除时间。
- `focus_timers`：计划事项 ID、预设分钟数、开始时间、结束时间、暂停时剩余秒数、状态和创建更新时间。只保留用于恢复与简单历史的必要字段。

设置继续存入现有 `settings`：常用模块、是否完成首次引导、计时声音开关和高级设置展开偏好。

## 数据流

1. 首页接口聚合今日计划、阅读记录、训练、餐食和主复盘，返回今日分项和总进度。
2. 首页接口从里程碑、交付物和计划发布日期派生自动倒计时，再与手动重要日期合并、按日期排序。
3. 长期目标服务根据关联类型调用独立计算器，生成自动进度；存在进度修正时优先显示修正值。
4. 启动计时器时，服务端保存开始时间和结束时间。页面每秒只更新显示，不每秒写数据库。
5. 暂停、继续、结束和计时完成时才写数据库；刷新后通过结束时间重新计算剩余秒数。

## 提醒与异常处理

- 浏览器不支持声音或自动播放被阻止时，只显示页面提醒，不报错。
- 倒计时日期无效、目标进度超出 0—100 或自定义计时小于 1 分钟时拒绝保存并说明原因。
- 自动关联来源被删除后，目标显示“来源不可用”，允许改为手动目标或删除，不静默丢失。
- 计时过程中本机休眠，恢复后按实际时间计算；已经结束则立即显示一次完成提醒。
- 所有新增记录沿用回收站、搜索、备份和导出机制。

## Demo 范围

正式开发前先制作可操作 Demo，使用示例数据展示：

- A 分层总览首页。
- 今日总进度环与五项状态。
- 两个重要日期倒计时。
- 两个长期目标及进度条。
- 任务的 25 / 45 / 60 分钟选择、运行、暂停和结束交互。
- 三步首次引导和简洁设置分组。

Demo 只用于确认布局、文案和交互，不写入用户的正式 SQLite 数据。

## 测试与验收

- 单元测试：今日进度权重、日期差、目标自动进度和计时状态计算。
- 集成测试：手动日期、目标关联、计时恢复、来源删除、搜索、回收站和导出。
- 组件测试：首页四层布局、倒计时状态、目标进度、计时器控制和首次引导。
- 真实页面验收：三套外观、浅深主题、窄屏布局、提示音关闭降级和无浏览器错误。

验收核心是：打开首页三秒内能说出今日完成度、最近重要日期、主要长期目标和当前正在计时的任务；首次设置可在一分钟内完成。

## 不在本次范围

- 多层目标树、OKR 评分和复杂里程碑系统。
- 系统级通知权限和后台推送。
- 自动完成任务或自动生成计划。
- 跨设备同步和多人共享目标。
- 复杂趋势图、排行榜和成就系统。
