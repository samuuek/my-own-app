# 读书模块设计规格

## 目标

在“生活”分组中新增与现有工作台一致的“读书”模块，用于管理书籍、持续记录阅读进度、在内置 PDF 阅读器中阅读，并为同一本书创建多篇带页码关联的阅读笔记。

## 产品范围

### 导航与外观

- 在“生活”导航组中新增“读书”，路由为 `/reading`。
- 页面沿用现有工作台的布局、页面标题、卡片、按钮、表单、弹窗、空状态和响应式规则。
- 同时适配流光玻璃、Notion 笔记和 Neo-Brutalism 三套外观；不创建独立设计语言。
- 新增读书模块图标，并在折叠侧栏、移动端导航、全局搜索和快捷新建中正确显示。

### 书架

- 书籍字段：书名（必填）、作者、封面图片（可选）、阅读状态、总页数、当前页、评分、简介和创建时间。
- 阅读状态固定为：想读、在读、读完、暂停。
- 书架支持按状态筛选，书籍卡片显示封面、书名、作者、当前进度、笔记数量和最近阅读时间。
- 未上传封面时使用与当前外观相符的默认书籍占位图。
- 纸质书或无 PDF 书籍仍可手动更新页码并记录笔记。

### 阅读进度与统计

- 每次更新进度都写入独立历史记录，包含记录日期、起始页、结束页、阅读分钟数和备注。
- 当前页不能小于 0；设置总页数后，当前页不能超过总页数。
- 完成百分比由当前页与总页数计算；未知总页数时显示当前页而不显示误导性百分比。
- 书籍详情显示完成百分比、累计阅读页数、累计阅读时长、笔记数量、最近阅读时间和进度历史。
- 到达总页数时提示是否将状态改为“读完”，不强制自动修改。

### 多次阅读笔记

- 一本书可以拥有任意多篇笔记。
- 笔记字段：记录日期、章节、起始页、结束页、原文摘录、读书感受、深入思考。
- 从 PDF 阅读器中新建笔记时，自动填入当前页作为起始页和结束页；用户可以修改页码并填写章节。
- 笔记支持新增、编辑、软删除、恢复、永久删除，并参与全局搜索。
- 书籍软删除后，其笔记和进度在常规页面隐藏；恢复书籍时全部重新可见。永久删除书籍时级联删除相关记录及 PDF 文件。

### PDF 上传与阅读器

- PDF 为可选附件；每本书最多关联一个 PDF，可替换或移除。
- 只接受经文件头校验的 PDF，默认最大 100 MB；错误类型、超限、损坏文件和不存在文件均显示明确中文提示。
- PDF 文件保存在本机工作台数据目录的专用附件目录，数据库只保存受控文件标识和元数据，不保存用户提供的原始路径。
- 下载和阅读接口只能通过书籍 ID 访问，并进行路径边界检查，不能读取任意本地文件。
- 内置阅读器使用 PDF.js 渲染，提供上一页、下一页、跳转页码、缩放、页数显示和继续上次阅读。
- 翻页时更新本地阅读位置；显式点击“记录进度”时写入进度历史，避免每次翻页产生冗余记录。
- 阅读器中的“添加笔记”自动关联当前页；无 PDF 时书籍详情仍提供手动笔记入口。

## 数据与接口

- 新增 `books` 表：书籍资料、状态、页数、当前页、评分、封面与 PDF 元数据。
- 新增 `reading_sessions` 表：每次进度更新及阅读时长。
- 新增 `reading_notes` 表：章节、页码范围、摘录、感受与思考。
- 使用新的顺序数据库迁移升级现有用户数据，不改动已有表，不要求清空数据库。
- 三类数据加入统一集合定义、状态加载、搜索、回收站和完整数据导出。
- 新增受限的封面/PDF 上传、读取、替换与删除接口；普通 JSON 接口继续沿用现有模式。
- 书籍可作为今日计划来源，创建“阅读：《书名》”事项并从今日计划返回读书模块。

## 文件、备份与恢复

- 附件目录位于现有 `MuziWorkspace` 数据根目录内，迁移电脑时复制整个数据目录即可保留文件。
- 完整 ZIP 导出包含书籍、进度、笔记数据和上传的 PDF/封面文件。
- 自动与手动数据库备份继续保证结构化数据；实现附件清单与恢复校验，界面明确标注附件是否完整，防止静默丢失。
- 上传采用临时文件后原子重命名；数据库写入失败时清理临时文件，替换成功后再删除旧附件。

## 页面结构

1. 读书首页：统计摘要、状态筛选、书架和“添加书籍”。
2. 书籍详情：资料与进度、继续阅读、记录进度、添加笔记、阅读历史和笔记列表。
3. 阅读视图：PDF 主阅读区、页码/缩放工具栏、可折叠笔记区；小屏幕上改为上下布局。
4. 新建/编辑弹窗：复用现有 `Modal`、`EntityForm`、`Button`、`Badge` 等组件。

## 错误处理与安全

- 所有数字字段在服务端验证范围，所有书籍关联 ID 验证存在性。
- 文件名由服务端生成 UUID，不信任上传文件名；响应使用安全的内容类型和下载文件名。
- PDF 接口保持仅限本机来源策略，不改变应用默认只监听 `127.0.0.1` 的安全边界。
- 文件缺失时保留书籍和笔记数据，显示“PDF 文件缺失”并允许重新上传，不导致页面崩溃。

## 验收与测试

- 数据迁移测试覆盖旧数据库无损升级及三个新表的外键、索引和级联行为。
- 接口测试覆盖书籍、进度、笔记 CRUD，进度边界，PDF 上传/替换/读取/删除，非法类型、超限和路径安全。
- 组件测试覆盖导航、书架筛选、统计、笔记表单自动页码和无 PDF 状态。
- 端到端测试覆盖添加书籍、上传 PDF、阅读翻页、保存进度、添加当前页笔记、搜索、回收站和恢复。
- 在三套外观及桌面/手机宽度进行视觉与交互检查。
- 最终执行项目完整的 lint、类型检查、单元/集成测试、构建、生产服务测试和端到端测试。

## 明确不包含

- EPUB/MOBI 阅读、OCR、PDF 文本自动摘录、云同步、多人账号、在线书库搜索和版权内容下载。
- 本次不改变当前本机 SQLite 架构为 Vercel/Supabase 云端架构；云端部署可作为后续独立项目。
