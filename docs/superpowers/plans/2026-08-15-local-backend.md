# 思屿本机个人版后端实施计划

**目标：** 建立独立、可测试、可持久化的本机后端，并将现有前端和桌面启动流程接入。

**技术方案：** Node.js HTTP + `node:sqlite` 模块化单体；Vite 开发代理；React 前端 API 客户端。

## 任务 1：数据库与仓储

- 先写临时数据库失败测试：初始化、议题 CRUD、空间自动保存、消息排序、搜索、备份恢复。
- 实现 schema、种子数据与仓储接口。

## 任务 2：HTTP API 与模型网关

- 先写接口失败测试：健康检查、校验、404、请求大小、模型列表、聊天持久化。
- 将现有模型注册表复用到独立服务，统一错误格式并隐藏密钥。

## 任务 3：前端持久化接入

- 先写 API 客户端和界面失败测试。
- 接入议题列表、工作空间加载、消息与旁注自动保存；保留 localStorage 一次性迁移。

## 任务 4：运行与验收

- 增加同时启动前后端的命令和 Vite 代理。
- 更新快捷方式脚本，等待后端健康后打开页面。
- 运行全部测试、类型检查、构建和真实 API 冒烟测试。
